# ⚡ Portfólio Profissional — Victor Ribeiro

Portfólio profissional estático desenvolvido para publicação contínua no **GitHub Pages**, combinando estética de terminal operacional, glassmorphism e foco no desenvolvimento backend/full-stack (PHP, Laravel, Python, MySQL).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estruturação acessível com tags nativas.
- **Tailwind CSS (CDN)**: Estilização responsiva sem necessidade de etapa de compilação ou Node.js.
- **CSS3 Personalizado**: Variáveis, efeitos de glassmorphism, barras de terminal e scanlines.
- **JavaScript Moderno (ES6+)**: Efeito typewriter no Hero, animação de rede conectada via HTML5 Canvas e controle de navegação.
